# Hi, I'm Ghodrat Rezaei

### Software & Computer Vision Engineer | Industrial Automation, Data & Cloud Applications

I'm a Software and Computer Vision Engineer at [Danieli Group](https://www.danieli.com/) and a master's graduate of [Politecnico di Milano](https://www.polimi.it/).

My work connects software with physical systems: developing vision applications, integrating industrial equipment, and turning sensor and process data into useful information. My projects span industrial automation, machine learning, data management, and cloud applications.

I enjoy working across the full problem—from understanding the process and collecting data to building the application and explaining the engineering decisions behind it.

## Areas of focus

- **Industrial software & automation:** PLC integration, process monitoring, data acquisition, and engineering applications.
- **Computer vision & machine learning:** object detection, tracking, segmentation, classification, and anomaly detection.
- **Data & cloud applications:** data pipelines, time-series analysis, databases, and event-driven API integration.
